# Güvenlik Politikası

## Desteklenen sürümler

Bu depo için ayrı bir sürüm destek tablosu yayımlanmamıştır. Güvenlik bildiriminizde etkilenen dosya, sürüm veya commit bilgisini belirtin.

## Güvenlik açığı bildirme

Lütfen olası güvenlik açıklarını herkese açık GitHub issue'larında veya tartışmalarda paylaşmayın.

GitHub deposunda **Security** sekmesi üzerinden **Report a vulnerability** seçeneği sunuluyorsa, bildiriminizi özel olarak iletmek için bu özelliği kullanın. Bu seçenek kullanılamıyorsa, depo sahibine GitHub profili üzerinden özel bir ileti göndererek güvenli bir bildirim kanalı isteyin.

Bildiriminize mümkünse şunları ekleyin:

- Etkilenen dosya, sürüm veya commit
- Sorunun kısa açıklaması ve olası etkisi
- Sorunu yeniden oluşturmak için gereken adımlar
- Varsa güvenli bir düzeltme önerisi

Kullanıcıların güvenliğini riske atmamak için açık ayrıntılarını düzeltme yayımlanana veya depo sahibiyle üzerinde anlaşılmış bir açıklama zamanı gelene kadar gizli tutun. Bildirimlerin alınacağına veya belirli bir süre içinde yanıtlanacağına dair garanti verilmez.
